# CIP-0003: Restructure Course Pedagogy: Application-First Approach

## Status
- [ ] Proposed
- [ ] Accepted
- [ ] Implemented
- [ ] Closed

## Description
Restructure the entire course pedagogy from a "mathematics-first" approach to an "application-first" approach to better engage students and improve learning outcomes.

## Motivation
Current feedback indicates that the course starts too abstractly with mathematical concepts, making it difficult for students to understand the practical relevance. The course needs to be restructured to:

1. *Motivate students* by showing real-world applications first
2. *Improve engagement* by connecting theory to practice
3. *Accommodate mixed skill levels* (UG, Masters, PhD students)
4. *Respect student workload* (25% effort, no evenings/weekends)

## Implementation

### Current Structure (Math-First)
1. Mathematical theory
2. Code implementation
3. Applied examples

### Proposed Structure (Application-First)
1. *Applied example* (e.g., marathon prediction, sensor data analysis)
2. *Code that solves the problem*
3. *Mathematical theory* behind the solution
4. *Extended exercises* for different skill levels

### Specific Changes Required

#### Lecture Structure
- *Start each lecture* with a compelling real-world example
- *Show working code* that students can run immediately
- *Explain the mathematics* in the context of the application
- *Provide tiered exercises* (basic, intermediate, advanced)

#### Content Organization
- *Week 1*: Linear regression with marathon data
- *Week 2*: Basis functions with sensor data
- *Week 3*: Bayesian methods with weather prediction
- *Week 4*: Gaussian processes with spatial data
- *Week 5*: Advanced topics with real-world projects

#### Practical Sessions
- *Decouple from lectures* - separate practical content
- *Focus on GitHub setup* and environment configuration
- *Use local datasets* instead of problematic pods package
- *Provide clear exercise expectations* (essay vs. code vs. discussion)

### Target Audience Considerations
- *Undergraduates*: Focus on applications and basic concepts
- *Masters students*: Add mathematical depth and implementation
- *PhD students*: Extended questions and research applications
